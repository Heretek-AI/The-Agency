# Research brief

## When to use

Use when the answer lives outside the repository (library docs, API
behavior, prior art). Do not present search snippets as verified facts.

## Procedure

1. Consult the primary source first (official docs, the package's own
   repository), then corroborate with a second source.
2. Pin versions: record the exact version the claim holds for.
3. Grade each claim high, medium, or low confidence and say what would
   raise it (a test, a newer doc, a maintainer answer).

## Good result

Claims, sources with links, versions, and confidence levels; a builder can
act on high-confidence claims and knows what to verify for the rest.
