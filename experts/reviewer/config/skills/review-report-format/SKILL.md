# Review report format

## When to use

Use for every review. The verdict is the headline; the findings are the
work order.

## Procedure

1. Open with the verdict: approve, or request changes.
2. List findings by severity (blocker, major, minor) with `file:line`
   and the exact problem.
3. Close with what you checked and ran, so the author trusts the scope.

## Good result

The author knows the verdict in ten seconds and the full fix list in five
minutes.
