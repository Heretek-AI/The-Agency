# Acceptance criteria

## When to use

Use for every story. A criterion without a runnable check is a wish.

## Procedure

1. Write each criterion as Given (the starting state), When (the action),
   Then (the observable outcome).
2. Name the check: the command, the page, or the request that proves it.
3. Cover the unhappy path at least once per story.

## Good result

qa can turn each criterion into a test without asking what it means.
