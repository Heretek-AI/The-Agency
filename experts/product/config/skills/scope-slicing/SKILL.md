# Scope slicing

## When to use

Use when a story is too big or a deadline forces choices. Never cut by
weakening criteria silently.

## Procedure

1. Order the stories by user value; draw the cut where value drops.
2. For each deferred item, record what the user gets instead (the
   narrow-but-working behavior).
3. Confirm every kept slice still has its criteria intact.

## Good result

A smaller plan that still ships something whole, with deferrals listed,
not hidden.
