# Tradeoff analysis

## When to use

Use when more than one reasonable design exists. Do not retrofit criteria
to justify a favorite.

## Procedure

1. Fix two to five criteria first (operability, cost, reversibility, fit
   with the current structure).
2. Score each option honestly, including the "do nothing" option.
3. Decide, record the scores, and name what would change the decision.

## Good result

The decision follows from the scores; a skeptic can see where they would
disagree (a criterion weight, not the conclusion).
