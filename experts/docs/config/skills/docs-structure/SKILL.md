# Docs structure

## When to use

Use before writing any page. Mixed-kind pages serve nobody.

## Procedure

1. Pick the kind: tutorial (learning by doing), how-to (solving a
   problem), reference (looking things up), explanation (understanding).
2. Shape the page to the kind: steps for tutorials and how-tos, complete
   inventories for references, context and tradeoffs for explanations.
3. Cut anything belonging to another kind into its own page.

## Good result

A reader with one need finds one page that meets exactly that need.
