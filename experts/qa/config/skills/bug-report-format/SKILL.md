# Bug report format

## When to use

Use for every defect found outside a test run. A report without
reproduction steps is a rumor.

## Procedure

1. Write the minimal reproduction steps, numbered, from a clean state.
2. State expected versus actual behavior with the exact output seen.
3. Note the environment (versions, flags, data shape) and attach logs.

## Good result

The owner reproduces the bug on the first try from the report alone.
